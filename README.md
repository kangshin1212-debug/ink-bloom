# Ink Bloom

잉크가 종이 위에 번지는 느낌을 그대로 재현한 브라우저 캔버스 드로잉 토이입니다. 순수 HTML/CSS/JavaScript만으로 만들어졌으며, 별도의 빌드 과정이나 의존성이 없습니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열기만 하면 됩니다.

```bash
# 예: 로컬에서 정적 서버로 열기
npx serve .
```

또는 파일 탐색기에서 `index.html`을 더블클릭해서 바로 열어도 됩니다.

## 사용법

- **드래그**: 마우스나 손가락으로 화면을 문질러서 잉크 자국을 남깁니다.
- **탭/클릭**: 화면을 짧게 톡 치면 더 크게 번지는 잉크 방울이 생깁니다.
- **종이**: 밝은 종이 / 어두운 종이 모드를 전환할 수 있습니다.
- **색감**: 각 종이 모드에 맞는 색상 팔레트 중에서 선택할 수 있습니다.
- **브러시**: 슬라이더로 브러시(잉크 방울) 크기를 조절합니다.
- **지우기**: 캔버스를 초기 상태로 되돌립니다.
- **저장**: 현재 캔버스를 PNG 이미지로 다운로드합니다.

## 기술

- Canvas 2D API를 사용한 실시간 드로잉
- Pointer Events로 마우스/터치 입력을 통합 처리
- 별도 라이브러리나 프레임워크 없이 순수 JS로 구현
